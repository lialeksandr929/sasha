## Описание
Приложение «Movie Library» позволяет управлять коллекцией фильмов. Пользователь может:
- добавлять фильмы с указанием названия, жанра, года выпуска и рейтинга;
- просматривать список фильмов в таблице;
- фильтровать фильмы по жанру и году выпуска;
- сохранять и загружать данные в/из файла `movies.json`.

## Инструкция по установке
1. Убедитесь, что у вас установлен Python 3.x.
2. Клонируйте репозиторий: `git clone https://github.com/lialeksandr929/sasha.git`
3. Перейдите в папку проекта: `cd sasha`
4. Запустите приложение: `python main.py`

## Инструкция по использованию
1. Заполните форму добавления фильма:
   - **Название** — введите название фильма;
   - **Жанр** — укажите жанр фильма;
   - **Год выпуска** — введите год выпуска (число);
   - **Рейтинг** — укажите рейтинг от 0 до 10.
2. Нажмите кнопку **«Добавить фильм»** — фильм появится в таблице.
3. Для фильтрации:
   - выберите жанр из выпадающего списка;
   - введите год в поле фильтрации;
   - нажмите **«Применить фильтры»**.
4. Чтобы сбросить фильтры — нажмите **«Сбросить фильтры»**.

## Примеры использования
- Добавление фильма:
  - Название: «Интерстеллар»
  - Жанр: «Фантастика»
  - Год выпуска: 2014
  - Рейтинг: 8.5
- Фильтрация:
  - Выберите жанр «Драма» — отобразятся только драматические фильмы.
  - Введите год «2020» — отобразятся фильмы 2020 года.

## Валидация ввода
- Название и жанр не должны быть пустыми.
- Год должен быть числом от 1888 до текущего года.
- Рейтинг должен быть числом от 0 до 10.

При некорректном вводе появится сообщение с ошибкой.
