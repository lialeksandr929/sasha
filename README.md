## Описание
**Movie Library** — это десктопное приложение с графическим интерфейсом (GUI) для учёта и организации личной коллекции фильмов.

Приложение позволяет:
* добавлять фильмы с указанием названия, жанра, года выпуска и рейтинга (0–10);
* просматривать все добавленные фильмы в виде таблицы;
* фильтровать фильмы по жанру (выпадающий список) и по году выпуска;
* сохранять данные о фильмах в формате JSON;
* загружать сохранённые данные при запуске приложения;
* проверять корректность вводимых данных (валидация).

**Технологии:**
* Python 3.x;
* библиотека `tkinter` для создания GUI;
* формат данных JSON для сохранения и загрузки.

## Установка и запуск

1. Убедитесь, что у вас установлен Python 3.x.
2. Скачайте или клонируйте репозиторий проекта.
3. Откройте терминал/командную строку и перейдите в папку проекта.
4. Запустите приложение командой:
   ```bash
   python main.py
Примеры использования
Пример 1: Добавление фильма
Заполните поля формы:
Название: «Интерстеллар»;
Жанр: «Фантастика»;
Год выпуска: 2014;
Рейтинг: 8.6.
Нажмите кнопку «Добавить фильм».
Фильм появится в таблице ниже.
Пример 2: Фильтрация по жанру
В выпадающем списке «Фильтр по жанру» выберите «Фантастика».

Пример 3: Фильтрация по году
В поле «Фильтр по году» введите 2014.
Нажмите кнопку «Фильтровать по году».
Таблица покажет только фильмы, выпущенные в 2014 году.
Пример 4: Сброс фильтров
Нажмите кнопку «Сбросить фильтры».
В таблице снова отобразятся все фильмы.
